# RISKS.md — Risk Register

Format: Risk | Category | Likelihood | Impact | Mitigation | Status

Likelihood: High / Medium / Low
Impact: High / Medium / Low
Status: Open / Accepted / Mitigated / Deferred

---

| # | Risk | Category | Likelihood | Impact | Mitigation | Status |
|---|---|---|---|---|---|---|
| 1 | **Stale cache trap:** User sees outdated app version indefinitely because SW serves old cached assets after a new deploy | PWA | High | High | Implement in-app "Update available — Reload" banner triggered by `workbox-window` `waiting` event. Never auto-reload silently. Provide explicit "Reload now" CTA. Test on every deploy. | Mitigated |
| 2 | **SW update notification not shown:** `waiting` SW detected but no UI shown due to event handler bug | PWA | Medium | High | Integration test the `workbox-window` event handler in CI. Include SW update banner in manual QA checklist on every deploy. | Mitigated |
| 3 | **SW scope mismatch:** SW registered at wrong scope fails to intercept all app requests | PWA | Low | High | Explicitly set `scope: '/'` in both SW registration call and Workbox config. Assert SW scope in Lighthouse PWA audit (score must be 100). | Mitigated |
| 4 | **IndexedDB quota exhaustion:** Browser revokes or restricts IDB storage under low-disk conditions | PWA | Low | High | Call `navigator.storage.persist()` on first app run to request durable storage. Monitor `navigator.storage.estimate()` in Settings screen; warn user if `usage/quota > 0.7`. | Mitigated |
| 5 | **Background Sync idempotency (future):** If Background Sync is added in v2, network retries could create duplicate events | PWA / Future | N/A | High | Not in scope for v1. Mitigation if added: use event `id` (UUID) as idempotency key on the server; deduplicate on sync. | Deferred |
| 6 | **iOS Safari PWA limitations:** No push notifications; Safari may evict SW and storage after ~7 days of non-use; IndexedDB soft limit ~50MB on older iOS; install requires explicit "Add to Home Screen" step | Platform | High | Medium | Call `navigator.storage.persist()` immediately on iOS. Show "Export data" reminder in Settings if > 7 days since last export. Document iOS limitations in onboarding. Encourage regular use to prevent eviction. | Mitigated |
| 7 | **`action_name_snapshot` not captured at log time:** Bug where `addEvent()` is called without copying Action display fields, resulting in events with empty/stale snapshots | Project | Low | High | Make `action_name_snapshot`, `action_icon_snapshot`, `action_color_snapshot` required non-optional fields in `Event` TypeScript interface (TypeScript will reject missing fields at compile time). Unit test `addEvent()` to assert snapshot fields are populated before IDB write. | Mitigated |
| 8 | **Suggestion algorithm cold start:** First-time user has no event history; suggestion scores are zero or meaningless; tiles appear random | Project | High | Low | Cold-start fallback defined in `SPEC.md § VIII.1`: when < 3 events exist in last 7 days, skip scoring and return pinned actions + `sort_order`. Onboarding guides user to create 2–3 actions and log them immediately. | Mitigated |
| 9 | **localStorage size limit with large action libraries:** `1td:actions` array could grow toward browser localStorage limit | Project | Low | Medium | Cap action library at 500 actions. Show warning banner in Library at 400 actions. 500 actions × ~300 bytes = ~150KB, well within typical 5–10MB limit. Monitor with integration test asserting serialized size < 2MB. | Mitigated |
| 10 | **IndexedDB write conflict (multiple tabs):** Two open browser tabs both attempt to log events simultaneously | Project | Low | Medium | IndexedDB handles concurrent writes from the same origin safely. UUIDs as keys prevent collision. Refresh timeline on `document.visibilitychange` event to ensure each tab shows latest state. | Mitigated |
| 11 | **Font FOUT / FOIT on slow connections:** Space Grotesk, JetBrains Mono, Newsreader fail to load before first paint; fallback fonts degrade "Temporal Field Journal" aesthetic significantly | Project | Medium | Medium | Define fallback font stacks in `tokens.css`: `Space Grotesk → system-ui, sans-serif`; `JetBrains Mono → ui-monospace, monospace`; `Newsreader → Georgia, serif`. Add `<link rel="preconnect" href="https://fonts.googleapis.com">` in `index.html`. Workbox caches fonts after first successful load for all subsequent visits. | Mitigated |
| 12 | **IndexedDB blocked during schema version upgrade:** Another open tab prevents `onupgradeneeded` from running; app hangs or fails to init | PWA | Low | Medium | Handle the `blocked` event in `openDB()` call: show toast "Please close other 1TD tabs to complete an update." Retry IDB open after `visibilitychange`. Document in `src/db/migrate.ts` comments. | Mitigated |
| 13 | **Data loss from browser storage clear:** User clears browser site data (intentionally or via device storage manager); all events and actions are permanently lost | Project | Medium | High | Surface prominent "Export your data" CTA in Settings. Show periodic reminder (once per week, tracked via `1td:settings.last_export`). Onboarding explains local-only nature and recommends regular export. No automatic backup in v1. | Mitigated |
| 14 | **Vite-plugin-pwa precache manifest over-inclusion:** Incorrectly configured `globPatterns` includes source maps, screenshots, or large dev assets; precache manifest bloats install payload | PWA | Low | Medium | Set explicit, minimal `globPatterns` in `vite.config.ts`: `['**/*.{js,css,html,ico,png,svg,woff2}']`. Exclude `screenshots/`. Inspect generated precache manifest size in CI build output; fail build if precache total > 1MB. | Mitigated |
| 15 | **Color token discrepancy: `#D8FF5E` vs `#cbf152`:** Brand description (Acid Chartreuse) and Material tokens (primary-container) define slightly different chartreuse values; components built against different tokens will have visual inconsistency | Project | Medium | Low | Both values defined in `tokens.css` as `--color-acid` and `--color-primary-container` respectively. All interactive CTA states must use `--color-acid`. Designer must reconcile to a single value before production launch. Track as open design debt. | Accepted |
